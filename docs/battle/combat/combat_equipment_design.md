# 전투 장비 스탯 개선 방안

## 0. 목적
- 이 문서는 `combat` 관점에서 장비가 전투 스탯에 어떻게 기여해야 하는지 기준을 정리한다.
- 현재의 `ATK / DEF / HP -> 직군별 환산` 구조를 정리하고, 장비 기본 스탯과 특수 능력의 책임을 분리한다.

## 1. 현재 문제
- 장비가 `ATK`, `DEF`, `HP` 3개만 가진다.
- 전투 계산 단계에서 이 3개를 직군별로 `물공`, `마공`, `속도`, `치확`, `명중`까지 임의 환산한다.
- 같은 장비가 직군에 따라 전혀 다른 의미로 바뀌어 장비 성능을 직관적으로 읽기 어렵다.
- 장비 데이터 자체가 실제 전투 스탯을 직접 설명하지 못한다.
- `치확`, `명중`, `흡혈` 같은 특수 성질이 기본 장비 스탯과 뒤섞이기 쉽다.

## 2. 목표 구조

### 2.1 장비 기본 스탯은 6개만 직접 가진다
- `체력`
- `물공`
- `물방`
- `마공`
- `마방`
- `속도`

### 2.2 그 외 스탯은 기본 장비 스탯이 아니다
- `치확`
- `치피`
- `명중`
- `회피`
- `상태적중`
- `상태저항`
- `물리관통`
- `마법관통`
- `흡혈`
- `회복력`
- `재생`

이 값들은 장비의 `특수 능력`으로만 부여한다.

## 3. 핵심 원칙
- 장비 기본 성능은 `6개 기본 스탯`만으로 읽혀야 한다.
- 장비 특수 성질은 `modifier` 또는 `passive`로 읽혀야 한다.
- 전투 직군 차이는 장비 환산식이 아니라 `캐릭터 기본 스탯`, `패시브`, `장비 제한`, `전용 효과`에서 나온다.
- 장비 기본 스탯은 전투 계산 시 그냥 합산한다.
- `직군별 장비 환산 로직`은 제거한다.

## 4. 모델 기준

### 4.1 EquipmentBlueprint
- 현재:
  - `attack`
  - `defense`
  - `health`
- 목표:
  - `maxHp`
  - `physicalAttack`
  - `physicalDefense`
  - `magicalAttack`
  - `magicalDefense`
  - `speed`

### 4.2 EquipmentInstance
- 인스턴스도 동일한 6개 기본 스탯을 저장한다.
- 인챈트 적용 전 기본값과 적용 후 총합값을 명확히 분리한다.

### 4.3 EquipmentEnchant
- 인챈트 기본 보너스도 같은 6개 스탯 축을 쓴다.
- 예:
  - `maxHpBonus`
  - `physicalAttackBonus`
  - `physicalDefenseBonus`
  - `magicalAttackBonus`
  - `magicalDefenseBonus`
  - `speedBonus`

### 4.4 장비 특수 능력
- 6개 기본 스탯 밖의 효과는 아래 둘 중 하나로 둔다.
  - `BattleModifier`
  - `BattlePassiveEffect`

## 5. 전투 반영 규칙

### 5.1 기본 장비 스탯 반영
- 장비의 `체력`, `물공`, `물방`, `마공`, `마방`, `속도`는 캐릭터 전투 스탯에 그대로 더한다.
- 예:
  - 장비 `물공 +12` -> 캐릭터 `물공 +12`
  - 장비 `마방 +7` -> 캐릭터 `마방 +7`
  - 장비 `속도 +3` -> 캐릭터 `속도 +3`

### 5.2 제거 대상
- `전사/도적/궁수는 ATK를 물공으로, 마법사는 ATK를 마공으로 환산`
- `도적은 장비 ATK 일부를 속도/치확으로 환산`
- `궁수는 장비 ATK 일부를 명중으로 환산`

이 규칙은 모두 제거한다.

### 5.3 직군 차이의 위치
- 직군 차이는 아래에서 표현한다.
  - 캐릭터 `(직업 × 티어 × 랭크)` 기본 스탯
  - 캐릭터 고유 패시브
  - 장비 착용 제한
  - 장비 특수 효과

## 6. 특수 능력 기준

### 6.1 modifier로 가야 하는 효과
- `치확 +5%`
- `명중 +8%`
- `회피 +6%`
- `흡혈 +3%`
- `재생 +0.02`
- `대 용병 피해 +12%`

### 6.2 passive로 가야 하는 효과
- `필중`
- `2회 공격`
- `첫 턴 선공`
- `반격`
- `상태이상 면역`

### 6.3 원칙
- 수치 보정은 `modifier`
- 판정 절차 변경은 `passive`

## 7. 예시

### 7.1 기본 무기
- `철검`
  - `물공 +12`

### 7.2 기본 방어구
- `가죽 갑옷`
  - `체력 +20`
  - `물방 +8`
  - `속도 +2`

### 7.3 기본 마도구
- `마도서`
  - `마공 +14`
  - `마방 +6`

### 7.4 특수 옵션 포함 장비
- `사냥꾼의 반지`
  - 기본 스탯:
    - `물공 +4`
    - `속도 +3`
  - 특수 능력:
    - `명중 +6%`

## 8. 인챈트 방향
- 인챈트는 기본적으로 `6개 기본 스탯 보정` 또는 `특수 능력 추가` 둘 중 하나다.
- 예:
  - `공격 인챈트` -> `물공 +3`
  - `가속 인챈트` -> `속도 +2`
  - `정밀 인챈트` -> `명중 +5%`
  - `흡수 인챈트` -> `흡혈 +2%`

## 9. 구현 변경 범위
- `features/town/domain/models/equipment_models.dart`
- 장비 blueprint/catalog 데이터
- 인챈트 보너스 구조
- `features/battle/domain/services/battle_combat_stat_service.dart`
- 장비 표시 UI
- 장비/전투 관련 테스트

## 10. 마이그레이션 순서
1. 문서 기준 확정
2. 장비 모델을 6스탯 구조로 개편
3. blueprint/catalog 데이터를 6스탯 기준으로 재작성
4. 인챈트 보너스를 6스탯 + 특수 능력 구조로 분리
5. `BattleCombatStatService`에서 직군별 환산 제거
6. 장비 UI를 6스탯 표시 기준으로 변경
7. 전투/캐릭터/장비 테스트 갱신

## 11. 최종 기준
- 장비 기본 능력은 `체력 / 물공 / 물방 / 마공 / 마방 / 속도`
- 그 외 전투 성질은 모두 `modifier / passive`
- 장비는 더 이상 직군별 환산의 입력값이 아니라, 실제 전투 스탯의 직접 원천이어야 한다.
