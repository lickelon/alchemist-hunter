# 전투 시트 재설계

## 0. 목적
- 전투 시트는 `텍스트 요약 패널`이 아니라 `실시간 전투 관제 화면`처럼 동작해야 한다.
- 가장 중요한 정보는 `현재 아군 / 현재 적 / 지금 무슨 일이 벌어지는지`다.

## 1. 상단 구조
- 상단은 그래픽 상태판으로 고정한다.

### 아군 패널
- 편성 캐릭터 이름
- HP bar
- 현재 HP / 최대 HP
- 사망 시 비활성 처리

### 적 패널
- 현재 encounter에 등장한 적 이름
- HP bar
- 현재 HP / 최대 HP
- 사망 시 비활성 처리

### 중앙 상태 배지
- 현재 phase
  - 탐색
  - 전투
  - 복구
  - 정지
- 현재 encounter 이름
- 현재 encounter 번호

## 2. 본문 구조
- 상단 상태판 아래 순서는 고정한다.

### 2.1 실시간 타임라인
- 최근 lifecycle 5~6개 표시
- 각 줄에 포함
  - actor
  - target
  - 피해 또는 회복 수치
  - 치명 여부
  - 빗나감 여부

### 2.2 런 요약
- 누적 골드
- 누적 에센스
- 누적 재료 종류 수
- 현재 run 승리 수
- 현재 encounter 번호
- 복구 중이면 남은 복구 시간

### 2.3 하단 진입 버튼
- `적 조합 / 드롭`
- `최근 기록`

## 3. 최근 기록 시트
- 최근 기록은 stage 단위 `encounter 로그`를 보여준다.
- 각 기록 항목에 포함
  - encounter 이름
  - encounter 번호
  - 성공 / 실패
  - full wipe 여부
  - 획득 보상
  - 행동 로그

## 4. 적 조합 / 드롭 시트
- 가능한 encounter 조합과 확률을 먼저 보여준다.
- 각 조합 아래에서 적 상세를 펼칠 수 있게 유지한다.
- 현재 활성 encounter가 있으면 시트 상단에서 따로 강조한다.

## 5. 표현 원칙
- 라이브 시트에서는 `총 행동 수`, `총 턴 수 예고`, `전투가 몇 초 뒤 끝나는지` 같은 사전 계산 정보를 보여주지 않는다.
- 텍스트는 보조 정보만 맡고, 전투 상태는 bar와 배지 중심으로 요약한다.
- `최근 결과`는 메인 시트에서 큰 카드로 반복하지 않고, 별도 기록 시트 진입으로 축소한다.
