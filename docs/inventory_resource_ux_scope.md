# 인벤토리 / 보유 자원 표시 범위

## 1. 목적
기존 Town / Workshop / Characters 선택 UI에서 자원 목록이 서로 다르게 보이는 문제를 줄인다.

## 2. 현재 자원 형태

| 자원 | 현재 상태 | 1차 표시 기준 |
| --- | --- | --- |
| 재료 | `player.materialInventory`의 `materialId -> count` 스택 | 아이콘, 이름, 희귀도, 보유 수량 |
| 원소 | `workshop.extractedTraitInventory`의 `traitId -> amount` 스택 | 아이콘, 이름, 보유량, potency |
| 포션 | `craftedPotionStacks` + `craftedPotionDetails`의 스택 | 아이콘, 이름, 품질, raw score, 보유 수량 |
| 장비 | `town.equipmentInventory`의 인스턴스 목록 | 아이콘, 이름, 슬롯, 6스탯, 인챈트 / 특수 효과 |

## 3. 공통 표시 규칙

- 목록은 기존 feature 화면 안에서 정리한다.
- 현재 selector를 유지하고, 전역 인벤토리 서비스는 새로 만들지 않는다.
- 목록 행은 아이콘, 이름, 핵심 수량 또는 핵심 상태만 보여준다.
- 자세한 정보는 기존 바텀시트나 feature 전용 상세 영역으로 보낸다.
- 사용자 표시명과 카탈로그 표시값을 기준으로 문구를 만든다.

## 4. 자원별 1차 범위

### 재료
- 목록 기준: 아이콘, 이름, 희귀도, 보유 수량
- 상세 보조 정보: 포함 원소, 사용처

### 원소
- 목록 기준: 아이콘, 이름, 보유량, potency
- 상세 보조 정보: 단일 / 복합 여부, 복합 원소 구성

### 포션
- 목록 기준: 아이콘, 이름, 품질, raw score, 보유 수량
- 상세 보조 정보: 원소 비율, 사용처
- 유지: raw 품질과 raw score는 과거 결정에 따라 노출 가능

### 장비
- 목록 기준: 아이콘, 이름, 슬롯, 핵심 스탯
- 상세 보조 정보: 6스탯, 인챈트, 특수 효과, 현재 장착 상태

## 5. 1차 적용 화면

- Workshop 보관함
- Town 대장간 보유 장비
- Town 포션 판매 선택
- Characters 장비 장착 화면
- Workshop 추출 / 제조 / 인챈트 / 부화 선택 화면

## 6. 완료 기준

- 기존 선택 UI에서 자원 행의 필드 순서와 용어가 맞다.
- 자원별로 스택 표시와 인스턴스 표시의 경계가 명확하다.
- 현재 상태 모델의 필드만 사용한다.
- 상세 정보는 카드 / 목록이 아니라 시트나 상세 영역에서 확인한다.
