# 재화 UX 정리

## 1. 목적

화면마다 다른 재화명과 부족 메시지를 통일한다.

사용자 화면에는 raw 영문 재화명이나 뭉뚱그린 `재화 부족` 문구를 남기지 않는다. 내부 식별자는 당장 바꾸지 않고, 먼저 UI 문구와 현재 기준 문서를 정리한다.

## 2. 공식 재화명

| 공식 영문 | 사용자 표기 | 설명 |
| --- | --- | --- |
| `Gold` | `골드` | 기본 경제 재화 |
| `Essence` | `정수` | 전투 보상으로 획득하고 부화 등에 사용하는 작업실 운영 재화 |
| `Fame` | `명성` | 포션 판매 등으로 획득하고 마을 성장에 사용하는 재화 |
| `Arcane` | `신비` | 재료 추출 완료 보상으로 획득하고 작업실 성장에 사용하는 재화 |
| `Element` | `원소` | 재료에서 추출되는 작업실 제작 자원 |
| `Material` | `재료` | 상점, 전투 등에서 얻는 제작 자원 |
| `Diamond` | `다이아` | 현재 플레이스홀더 재화 |

`Trait / 특성`은 작업실 제작 자원명으로 쓰지 않는다. 작업실 추출 자원은 모두 `Element / 원소`로 통일한다. 상세 기준은 [Element 용어 통일 방안](./element_terminology_unification_plan.md)을 따른다.

## 2.1 기존 구현명 매핑

아래 이름은 공식 재화명이 아니라 기존 구현명 또는 폐기 예정 이름이다. 사용자 화면과 신규 문서에서는 공식명을 사용한다.

| 기존 구현명 | 공식명 | 사용자 표기 |
| --- | --- | --- |
| `townInsight` | `Fame` | `명성` |
| `TownInsight` | `Fame` | `명성` |
| `arcaneDust` | `Arcane` | `신비` |
| `ArcaneDust` | `Arcane` | `신비` |

## 3. 폐기 표현

| 폐기 표현 | 대체 표현 |
| --- | --- |
| `에센스` | `정수` |
| `TownInsight` | `Fame` 또는 `명성` |
| `TownSight` | `Fame` 또는 `명성` |
| `마을 통찰` | `명성` |
| `마을 인사이트` | `명성` |
| `ArcaneDust` | `Arcane` 또는 `신비` |
| `아케인 더스트` | `신비` |
| `비전` | `신비` |
| `Trait / Element` | `Element` 또는 `원소` |
| `Element / Trait` | `Element` 또는 `원소` |
| `추출 특성` | `추출 원소` |
| `특성 재료` | `원소` |

## 4. 표시 규칙

재화 수량은 짧은 한글명과 수량을 붙여 쓴다.

| 상황 | 표기 예시 |
| --- | --- |
| HUD | `골드 120 / 명성 8` |
| Workshop HUD | `정수 120 / 신비 14` |
| 비용 | `골드 30 / 명성 2` |
| 부화 비용 | `정수 40 / 신비 6 / 재료 2종 / 원소 1종` |
| 보상 | `골드 +35 / 정수 +6 / 재료 1종` |
| 원소 재고 | `원소 3종` |
| 원소 상세 | `Vital 원소 0.80` |

보조 설명이 필요할 때만 `신비 가루`, `추출 원소`처럼 풀어 쓴다. 일반 카드 summary와 HUD에서는 짧은 표기를 우선한다.

## 5. 부족 메시지

부족 메시지는 원인을 직접 말한다.

| 상황 | 메시지 |
| --- | --- |
| 골드 부족 | `골드 부족` |
| 정수 부족 | `정수 부족` |
| 명성 부족 | `명성 부족` |
| 신비 부족 | `신비 부족` |
| 원소 부족 | `원소 부족` |
| 특정 원소 부족 | `{원소명} 원소 부족` |
| 재료 부족 | `재료 부족` |
| 특정 재료 부족 | `{재료명} 부족` |
| 포션 부족 | `포션 부족` |
| 큐 슬롯 부족 | `작업실 큐가 가득 찼습니다` |

사용하지 않을 메시지는 아래와 같다.

- `재화 부족`
- `특성 부족`
- `특성 재료 부족`
- `에센스 부족`
- `아케인 더스트 부족`
- `TownInsight 부족`

## 6. 우선 적용 위치

1차 적용 위치는 아래로 제한한다.

- Town 스킬트리 비용과 부족 메시지
- Workshop 스킬트리 비용과 부족 메시지
- 호문쿨루스 부화 시트 비용과 부족 메시지
- 제작 enqueue 실패 메시지
- 추출 enqueue 실패 메시지
- 인챈트 enqueue 실패 메시지
- 메인 카드 summary
- 전투 결과 / 수령 대기 / 최근 로그의 보상 표기

공통 formatter는 자연스럽게 들어갈 위치가 있으면 추가한다. 단, 전역 추상화를 먼저 만들지는 않는다.

## 7. 구현 원칙

- UI 문자열부터 정리한다.
- 내부 저장 필드명 변경은 별도 리팩토링으로 분리한다.
- `TownInsight`, `ArcaneDust` 같은 기존 내부 필드가 남아 있어도 사용자 화면에는 `명성`, `신비`로 표시한다.
- `Element` 내부 구현이 아직 `trait` 필드를 쓰더라도 사용자 화면에는 `원소`로 표시한다.
- 테스트 기대 문자열은 사용자 표기 기준으로 갱신한다.

## 8. 완료 기준

- 사용자 화면에 `Essence`, `TownInsight`, `ArcaneDust`, `Trait` 같은 raw 재화명이 노출되지 않는다.
- 사용자 화면에 `에센스`, `마을 통찰`, `아케인 더스트`, `특성 재료` 같은 폐기 표현이 남지 않는다.
- 부족 메시지는 `골드 / 정수 / 명성 / 신비 / 원소 / 재료` 단위로 분리된다.
- 메인 카드 summary, 스킬트리, 부화, 제작/추출/인챈트 실패 메시지가 같은 용어를 사용한다.
- 문서와 테스트 설명도 현재 사용자 표기 기준을 따른다.
