# 가격 / 드롭 / 제작시간 곡선과 경제 지표

## 1. 목적
가격, 드롭, 제작시간, 보상 곡선을 조정할 때 확인할 기준을 정리한다.

이 문서는 현재 카탈로그 수치를 기준선으로 삼고, 이후 조정 시 어떤 지표를 같이 봐야 하는지 정의한다.

## 2. 현재 기준선

### 전투 보상

| Stage | 권장 전투력 | 탐색 | 복구 | 성공 골드 | 성공 정수 | 성공 XP |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 폐허 입구 | 210 | 7초 | 10초 | 24 | 4 | 16 |
| 먼지 회랑 | 300 | 9초 | 12초 | 42 | 6 | 24 |
| 재의 공방 | 390 | 11초 | 14초 | 60 | 9 | 34 |
| 폭풍 전시실 | 490 | 14초 | 16초 | 86 | 13 | 46 |
| 문물의 핵 | 580 | 15초 | 18초 | 112 | 18 | 58 |

실패 전투는 골드, 정수, 재료, XP를 지급하지 않는다.

### 상점 가격

| 상점 | 품목 | 가격 | 수량 | 갱신 | 강제 갱신 |
| --- | --- | ---: | ---: | ---: | ---: |
| 일반 상점 | `m_1` ~ `m_8` | 50 | 20 | 15분 | 25 + 15씩 증가 |
| 촉매 상점 | `m_25` ~ `m_30` | 180 | 8 | 30분 | 90 + 45씩 증가 |

일반 재료 1개는 Stage 1 성공 보상 약 2회분보다 비싸다. 촉매 재료 1개는 Stage 3 성공 보상 3회분과 같다.

### 제작 / 작업 시간

| 작업 | 현재 시간 |
| --- | ---: |
| 포션 제조 | 반복 1회당 15초 |
| 장비 제작 | 기본 30초 |
| 장비 인챈트 | 20초 |
| 재료 전체 추출 | 수량 1개당 20초 |
| 재료 선택 추출 | 수량 1개당 30초 |
| 호문쿨루스 부화 | 45초 |

### 포션 판매가

포션 기본가는 `p_1 = 100`에서 시작해 포션 ID 순서마다 25씩 증가한다.

품질 배율은 아래 기준을 따른다.

| 품질 | 점수 기준 | 판매 배율 |
| --- | ---: | ---: |
| S | 0.92 이상 | 1.6 |
| A | 0.78 이상 | 1.3 |
| B | 0.58 이상 | 1.0 |
| C | 0 이상 | 0.8 |

Town 스킬트리의 포션 판매 보너스는 최종 판매가에 곱해진다.

## 3. 곡선 원칙

### 가격 곡선

- 상점 가격은 전투 보상보다 빠르게 오르면 안 된다.
- 일반 재료는 초반 반복 구매가 가능한 가격대를 유지한다.
- 촉매 재료는 상점만으로 대량 구매하기 어렵고, 전투 드롭과 병행하게 만든다.
- 강제 갱신 비용은 연속 사용을 억제하되, 필요한 순간 선택 가능한 비용이어야 한다.
- 포션 판매가는 초반 골드 공급원 역할을 하되, 상점 재료 무한 구매를 쉽게 만들 정도로 높이면 안 된다.

### 드롭 곡선

- 전투 stage가 올라갈수록 보상 골드, 정수, XP는 단조 증가한다.
- 재료 드롭은 적 단위 근거를 가진다.
- 사용자 화면은 조합 확률이 아니라 stage별 고유 적과 적별 드롭 근거를 보여준다.
- 상점 재료도 전투에서 얻을 수 있어야 한다.
- 같은 재료가 여러 stage에서 반복적으로 풀리면 stage 정체성이 약해지므로 조정 근거가 필요하다.

### 제작시간 곡선

- 짧은 반복 작업은 15~30초 단위로 유지해 큐가 자주 움직이게 한다.
- 장비 제작과 부화는 포션 제조보다 길어야 한다.
- 선택 추출은 전체 추출보다 오래 걸리는 대신 원하는 결과를 노리는 선택지로 둔다.
- 큐 보너스와 제작 효율 보너스가 붙어도 작업 완료 빈도가 지나치게 압축되지 않아야 한다.

## 4. 점검 지표

### 인플레이션 지표

| 지표 | 확인 목적 |
| --- | --- |
| 골드 순증 | 전투 보상 + 포션 판매가 상점 / 고용 / 스킬트리 소비를 초과하는지 확인 |
| 정수 순증 | 전투 보상 정수가 부화 / 작업실 운영 비용보다 과하게 쌓이는지 확인 |
| 신비 순증 | 추출 보상 신비가 Workshop 스킬트리와 부화 비용을 무력화하는지 확인 |
| 원소 재고 증가율 | 추출 반복이 원소 비용을 너무 쉽게 해결하는지 확인 |
| 포션 판매 회수율 | 포션 제조 입력 대비 골드 회수가 너무 높은지 확인 |

### 병목 지표

| 지표 | 확인 목적 |
| --- | --- |
| 특정 재료 부족률 | 한 재료가 장비 / 부화 / 추출 흐름을 과하게 막는지 확인 |
| 정수 부족률 | 전투 진행 없이 Workshop 진행이 막히는 빈도 확인 |
| 신비 부족률 | 추출 반복 요구량이 과한지 확인 |
| 원소 부족률 | 특정 원소 비용이 진행을 고정 루트로 몰아가는지 확인 |
| 큐 대기시간 | 작업 완료보다 대기 슬롯 부족이 더 큰 병목인지 확인 |

### 이탈 위험 지표

| 지표 | 확인 목적 |
| --- | --- |
| 평균 접속 간격 | 실제 플레이 리듬이 큐 / 전투 시간과 맞는지 확인 |
| 접속당 처리 액션 수 | 접속 시 수령 / 등록 / 편성 / 판매 행동이 충분한지 확인 |
| 수령 대기 누적 시간 | 보상이 쌓였는데 사용자가 회수하지 않는 구간 확인 |
| 빈 큐 지속 시간 | 다음 작업을 넣을 이유가 약한 구간 확인 |
| 반복 실패 후 정지율 | stage 난이도 또는 회복 시간이 이탈로 이어지는지 확인 |

### 후반 전이 지표

| 지표 | 확인 목적 |
| --- | --- |
| Stage 5 반복 성공률 | 후반 전투가 안정 파밍으로 전환되는 시점 확인 |
| 3연승 해금 소요 시간 | 다음 stage 해금이 과하게 길거나 짧은지 확인 |
| 장비 교체 주기 | 새 장비 제작의 체감 가치 확인 |
| 인챈트 시도 간격 | 포션 / 원소 / 장비가 인챈트 루프를 충분히 유도하는지 확인 |
| 부화 시도 간격 | 호문쿨루스 부화 비용이 후반 목표로 작동하는지 확인 |

## 5. 수동 점검 기준

밸런스 수치를 조정할 때는 개별 숫자보다 곡선 형태를 먼저 확인한다.

- stage 보상은 골드, 정수, XP가 stage 순서대로 증가한다.
- 실패 보상은 항상 0이다.
- 상점 강제 갱신 비용은 같은 주기 안에서 증가한다.
- 포션 판매가는 품질 순서 `S > A > B > C`를 지킨다.
- 선택 추출 시간은 전체 추출 시간보다 길다.
- 부화 시간은 포션 제조 1회보다 길다.
- 장비 제작은 재료 비용을 가진다.
- 각 stage는 최소 1개 이상의 encounter를 가진다.
- 각 적은 유효한 스탯과 드롭 정보를 가진다.

## 6. 적용 순서

1. 상점별 구매 제한, 품절, 재입고 정책은 현재 상점 seed 기준으로 적용한다.
   - 일반 상점: 상품별 주기 한도 20개 / 15분마다 재입고
   - 촉매 상점: 상품별 주기 한도 8개 / 30분마다 재입고
   - 재고 0개는 품절이며, 자동 / 강제 갱신 시 seed 재고로 복구한다.
2. 실제 JSON 외부화는 DTO 경계와 검증 규칙이 충분히 안정된 뒤 진행한다.
